## 🚀 HOW TO USE

### 1. View the Project

**Windows:**
```powershell
cd "D:\Decode-Labs\Decode-Labs Project"
python -m http.server 8080
# Open: http://localhost:8080
```

**Mac/Linux:**
```bash
cd ~/Decode-Labs/Decode-Labs\ Project
python3 -m http.server 8000
# Open: http://localhost:8000
```

**Direct:**
- Double-click `index.html` in file explorer
- Opens in default browser

### 2. Test Responsiveness
- Open DevTools: F12
- Toggle device toolbar: Ctrl+Shift+M
- Test mobile, tablet, desktop sizes

### 3. Test Accessibility
- Use Tab key to navigate (keyboard only)
- Press Escape to close mobile menu
- Check with screen reader (NVDA, JAWS, VoiceOver)
- Use browser DevTools → Accessibility audit

### 4. Customize
- **Colors:** Edit `:root` in `styles.css`
- **Fonts:** Update Google Fonts link in `index.html`
- **Content:** Edit HTML sections
- **Spacing:** Change `--spacing-*` variables

### 5. Deploy
- Copy all files to your hosting
- No build process needed
- No dependencies required
- Works on any web server
